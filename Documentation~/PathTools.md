# 路径工具 / Path tools

作者 CH。打开 **Tools → CH自定义工具集 → 场景工具 → 路径工具**。所有功能内嵌同一个窗口，语言共用“设置 → 常规”；默认跟随 Unity，可改中文或 English。无需 ASE、Shader Graph、Unity Splines 或付费路径插件。

## 快速开始

1. 选择“直线 / S形曲线 / 圆形 / 空间飞行”，点击“创建路径”。路径放在 Scene 当前观察中心。
2. 在“编辑路径”点击“在场景中编辑”，拖动带编号的路径点。默认自动平滑；关闭某点的“自动平滑”后，可分别编辑进入/离开控制柄。点的位置与控制柄采用路径局部坐标，扭转采用角度。
3. 切换“沿线放模型 / 生成网格 / 路径运动”。修改路径后重新生成静态输出；运行时运动会读取变化后的路径。

每世界单位按1米处理。采样在**变换后的世界空间**执行，非均匀缩放也计入实际长度。自动平滑不适合所有拐角，可手动调整控制柄。表面吸附选项只在拖动点时向世界下方寻找表面，不会自动把整段曲线贴合地形；它复用工具集的可见 Collider/静态 Mesh 拾取，不修改碰撞器。

## 沿路径放置模型

拖入 Project 中的预制体/模型或场景对象，设置间距后生成。Prefab 实例保留关联；场景对象按当前层级复制。模型保持原有网格和 UV，不执行弯曲变形。朝向可选跟随路径、保持竖直或固定世界旋转；支持局部位置偏移、旋转修正和缩放倍率。默认前方 +Z、上方 +Y，例如模型前方为 +X 时可用 Y=-90° 修正。

“补上终点”只作用于开放路径，最后一段可能小于设定间距。闭合路径始终排除重复末端。生成组是独立场景根节点，世界尺度保持为1；它与路径通过组件引用关联。移动路径后需要重新生成，输出不会被路径的非均匀缩放再次拉伸。

## 标线、面片、圆管与栏杆

网格类型包含连续面片、虚线、方向箭头、圆管和栏杆。面片可生成双面；圆管可配置圆周边数与端面；栏杆包含1–4根横杆和按距离放置的立柱。横杆与立柱使用两个 submesh，可分别指定材质。此处为视觉几何生成，不是建筑结构计算，也不会添加 Collider。

宽度、半径、高度、间距和分段长度均采用世界米。网格保存目录支持拖入 Unity Project 的 Assets 文件夹，或选中目录后点击“使用选择目录”。每次创建独立、唯一的 `.asset`，不会覆盖既有资源。把材质拖入材质栏即可使用自己的 Shader / ASE / Shader Graph 特效材质；留空则创建当前 Built-in / URP / HDRP 管线的默认 Lit 材质。自定义材质需要自行与当前管线兼容。

| 数据 | X / U | Y / V |
| --- | --- | --- |
| UV0 / TEXCOORD0 | 面片横向0–1；圆管绕圆周0–1 | 世界距离 ÷ 每次重复长度，再应用 UV 平铺倍率和偏移 |
| UV1 / Unity `mesh.uv2` / TEXCOORD1 | 横向或圆周0–1 | 整条路径进度0–1；立柱则为底部0到顶部1 |

虚线/箭头使用整条路径的累计距离，空白不会让 UV 从头开始。立柱 UV0 的纵向增量使用自身高度，起始值保留其沿路径位置；UV1 纵向独立表示底到顶。端面沿边缘使用圆周坐标，适合纯色/流动材质，未制作无拉伸的径向图案 UV。UV1 是特效坐标，**不是无重叠光照贴图 UV**；烘焙光照前需另做 lightmap UV。法线、切线与圆管 UV 接缝顶点一并生成。

宽网格在急弯或自交曲线处仍可能重叠。工具不做布尔合并、碰撞避让、等宽拐角求交、地形连续投影或自动LOD。请调整路径、宽度与分段距离。最多512个路径点、24000个采样点、10000个放置位置、单网格200000顶点，超限明确停止；这些是防止误操作的上限，不是性能推荐值，未做移动端/GPU基准测试。

## 路径运动与鸟飞行

先创建“空间飞行”闭合路径，再在“路径运动”点击“创建飞行演示”。演示仅使用原创几何占位外观。把鸟的模型/Prefab放到生成的运动根物体下，替换外观子物体即可；鸟的 Animator 留在外观上控制翅膀，根物体由 `PathFollower` 控制位置和朝向。也可以把任意独立场景对象指定为运动根物体。

支持米/秒速度、起始距离、反向、终点停留/循环/往返、沿路径朝向/世界上方向/只移动位置、局部偏移、模型轴向修正、前视距离、运行时旋转平滑和限幅转弯侧倾。跟随路径包含俯仰，竖直段使用稳定备用上方向；闭合路径分配接缝扭转修正。最大侧倾角度设0可关闭侧倾。世界上方向模式仍沿三维切线俯仰，仅尽量保持世界上方；竖直切线使用备用方向。

循环开放路径会从终点跳回起点，界面会提示。连续飞行优先闭合路径；往返会在端点改变运动方向，旋转平滑控制转头，不包含加减速、物理惯性或飞行动力学。默认以查表弧长实现近似恒速；采样误差受最大采样间距和曲线误差控制。侧向偏移的轨迹长度与中心路径不同，因此偏移后的物体速度不是严格恒速。

点击“预览路径运动”可在编辑状态查看；停止、切换工具页、关闭窗口、脚本重载、场景关闭或切换 Play 模式会恢复原局部位置/旋转/缩放。预览不是动画录制。进入 Play 后组件会自动运行，不需要工具窗口保持打开；`Restart()`、`Pause()`、`PoseAt(seconds)`、`DistanceAt(seconds, out backwards)` 和 `Apply(seconds)` 可供脚本调用。手动 `Apply` 或预览使用确定时间姿态，运行时 Update 另外应用转向平滑。

运动路径不能是运动物体自身或它的子级，否则会形成自驱动坐标反馈。零尺度、无效数值或退化长度会阻止生成或停止运动并报告原因。

## 保存、重建和撤销

路径点、生成和组件添加支持 Undo。重建只替换该路径对应的工具生成组；**该组内的手动编辑也会替换**。其他对象保留。不要给非工具对象添加 `PathGeneratedOutput` 标记。Undo 撤销场景生成后，新 `.asset` 仍保留供 Redo 使用；确认不需要后，可自行删除未引用的历史网格资产。工具不自动清理用户资产。

运行时组件位于独立的 `CH.CustomTools.Paths` 程序集，可参与 Player 编译；原 Shader 转换核心继续不依赖 Unity API。验证环境为 Windows D3D11、Unity 2022.3.10f1 / 6000.0.80f1；实际检查范围见 `Evidence/PathTools060/verification.json`。这不表示其他 Unity/SRP 版本、独立 Player 或所有硬件已测试。
