# CH自定义工具集 0.6.2

作者：CH。统一入口 **Tools → CH自定义工具集**。左侧为 Shader、VFX、场景工具、设置，右侧的功能标签直接切换当前面板，不再打开新的功能窗口。原 Shader 包升级后就是完整工具集；包 ID 保持 `com.aseshader.handwritten-converter`。

## 功能页标题

所有功能页采用统一英文标题（如 `AUDIO / RHYTHM CURVES`、`SHADER / GRAPH CONVERSION`、`PATH / CREATION & MOTION`）。前缀和 `/` 为白色 `#FFFFFF`，功能名为橙色 `#FF7711`；字号20、粗体，窄窗口自动换行。标题固定显示在功能内容上方，滚动时仍可辨认当前页面。下方说明、菜单与控件继续跟随全局中文/English设置。

## 音频曲线

拖入或选择 AudioClip，调整包络响应、释放、起音间隔、阈值和脉冲响应。高级设置包含采样率、FFT 大小、静音阈值和关键帧压缩误差。压缩/流式音频可点击创建解压分析副本；只改副本的导入设置，保留原音频。

分析得到音量包络、低频、中频、高频、起音强度、节奏脉冲六条可编辑曲线，并记录检测到的节拍及 BPM 估计。BPM 是估计值，不能保证任意音乐都识别正确。预览支持游标、前后起音定位和编辑器音频试听，不在场景中创建 AudioSource。

选择通道后设置输出最小/最大值、指数、反相及时间偏移。可保存六通道数据 `.asset`、复制曲线、导出 `.anim`（等比缩放、Y 位移、Light 亮度、Renderer 材质 Float），或应用到场景粒子的发射率、初始大小、初始速度。支持包含子粒子、时长对齐、循环和 Undo。粒子三轴初始大小不会被悄悄替换为单轴。输出使用新路径，保留同名资源。

子特效时序支持相对 Animator 根物体的多轨显示、隐藏和定时显示，单独导出或追加到当前动画。重叠或同一时刻矛盾的区间会阻止导出。导出为 Unity 原生动画曲线，不依赖运行时插件。

## 场景测量

在场景工具中启用 Scene 测量，左键放点，右键或 Enter 完成，回到起点闭合面积。支持顶点 / 线段拖动、当前场景 Undo、标题与颜色修改，以及旧 WorkBuddy 记录导入。按 1 世界单位 = 1 m 显示；角度为较小夹角，面积只接受共面无自交边界。记录位于本机 EditorPrefs，不写场景。详见 [场景测量](SceneMeasurement.md)。

## 资源整理

命名方式选择 **自定义组合** 后，按顺序添加前缀、特效名、原文件名、序号或自定义文字。↑ / ↓ 调整顺序，× 删除片段；每行“连接文字”填写下划线、短横线等分隔内容，留空则直接相连。序号可选 1 / 01 / 001 等位数，扩展名自动保留。下方实时显示完整示例，扫描后显示实际资源的改名预览。原命名方案解析成这些选项，保存格式仍兼容已有方案，无需编辑占位符。

添加 Project 预制体或场景特效实例，扫描递归资源依赖。按资源类型配置目录、前缀、原名/特效名/序号规则，预览每个目标路径，并可排除资源。默认保留共用资源、入口预制体及 Unity 特殊目录；字符串形式加载的路径需要使用者自行排除。

执行前确认预览；移动通过 AssetDatabase 完成以保留 GUID，并生成当前项目的恢复记录。资源或层级发生变化后会使预览失效；执行时也会复查引用。路径恢复通过整理记录完成，保留整理后对资源内容的编辑。整理记录位于项目 `Artifacts/VfxResourceOrganizer`，不会被工具包升级删除。

## 从旧独立音频插件升级

新版完整包含 AudioRhythmCurves 1.0.9 的音频和资源整理功能，不需要再安装第二个依赖包。代码命名空间为 `CH.CustomTools.VFX`，与旧独立包的 `AudioRhythmCurves` 类型和 MonoScript GUID 区分，允许升级期间同时安装。

1. 在设置 → 常规，或音频面板点击 **迁移旧版曲线数据（创建副本）**。
2. 选择当前项目 Assets 中旧插件保存的 `.asset`。工具在同一目录创建新的 `_CH.asset`（重名自动编号），打开兼容副本。
3. 原文件及其 GUID、音频引用、已有 `.anim` 和粒子数据保留。副本不会自动改写其他资源对原曲线数据的引用；若自定义编辑器引用旧数据，请主动改用副本。
4. 确认副本后，可通过 Package Manager 移除旧独立音频包。若旧插件以 Assets 源码导入，只清理旧代码，保留曲线、音频、AnalysisCopies 和导出资源。

支持 Unity 文本序列化的旧单对象曲线资源；二进制资源需先在旧插件中以文本格式重新保存。迁移严格检查原脚本 GUID 和数据字段，原文件不被修改。资源整理方案沿用原来按项目存储的设置键；历史整理记录仍可选择恢复。

## 安装、更新与语言

在 Package Manager → Add package from git URL 输入：

```
https://github.com/Ch47369/CHCustomTools.git
```

固定本次版本可使用 `https://github.com/Ch47369/CHCustomTools.git#v0.6.2`。仓库现为公开，安装和更新无需 GitHub 登录。首次用 Git URL 安装需要 Unity 能找到 Git；离线可安装同版本 Unity Tarball，不需要另取音频包。

更新在设置 → 插件更新中进行；HTTPS 安装从 GitHub Release 查询正式版本，只有严格高于当前版本才提供版本更新操作。下载通过 GitHub API 进行，验证发布资源的大小和 SHA-256，再交给 Unity 安装。安装包保存在当前项目 `Packages/CHCustomToolsCache~`，项目的包引用随之改为该文件；后续仍从 GitHub 检查和下载更新，不读取开发者本地仓库。请把此缓存目录连同 manifest 一起保留，便于项目在其他机器恢复。SSH 安装保留原 Git 传输方式。

首次仍可用 Git URL 安装；更新后 Package Manager 的底层来源可能显示 Local tarball，工具窗口会显示 GitHub Release。包文件来自公开的 GitHub 正式发布资源。旧地址 `Ch47369/ShaderConverter` 继续兼容，新安装使用 `Ch47369/CHCustomTools`。

公开更新不调用 Git 凭据管理器，不读取本地 Git 仓库，也不要求登录。HTTPS 更新通过 GitHub API 查询并下载，使用并行分段请求、范围检查、大小和完整文件 SHA-256 校验；只有校验通过才交给 Unity 安装。旧版若因 Git 克隆超时而无法更新，请先手动安装一次 0.4.9 Tarball，以启用新更新器。

语言只有中文、English 两种显示。未手动选择时跟随 Unity 编辑器语言；设置 → 常规中手动选择后影响全部功能，恢复默认清除覆盖。作者始终为 CH。

最低 Unity 2022.3。音频/VFX及窗口在 Unity 2022.3.10f1 和 6000.0.80f1 实测；这不扩大 ShaderGraph 的 Unity 2022.3 / SG14.0.8 版本限制。已有转换能力、管线宿主要求和阻塞条件参见 ShaderConversionRoadmap.md，不宣称任意 Shader 都能自动互转。
