# 材质分类、设备、性能与批量生成

统一入口：**Tools → ASE Shader Converter → ASE 着色器库**。人物说明已进入对应分类，独立人物库菜单取消。

## 同一材质方案与三条管线

浏览器把同一个 `familyId` 的 Built-in、URP、HDRP 放在同一卡片。`familyContracts` 以原图/源码 SHA-256 或同一个原创生成方案为身份，记录三个目标的功能映射、缺口与宿主要求。0.3.5 有 110 个同源方案、290 份实际图；90 个有三份文件。默认显示当前管线全部已验证版本（90/90/110），包括明确标注的功能缺口；可切到三目标功能已映射的 65 个方案，或其余 45 个缺口方案。详见 [逐方案表](CrossPipelineLibrary.md)。

完整三层视差流麻可搜索 `源码适配 流麻 PC 高` 或点击专用浏览按钮，按当前管线安装即可绑定原创示例贴图。配色预设只在用户主动点击时应用到选中流麻材质，支持撤销；重复安装保留已有材质参数。该效果静态图含 93 个采样位置，三层各最多 15 次迭代，属于 PC 高复杂度，目标 4.5，不标记 Mobile/Pad 候选。详情见 [完整效果说明](Evidence/Showcase035/README.md)。

新增四个 Kino 图像滤镜可检索 `Kino`、`暗角`、`故障` 或 `万花筒`。一键生成的是可编辑 Shader 与材质，宿主仍需提供输入纹理和全屏绘制，不自动增加相机后处理组件。数字故障的历史帧/噪声、模拟故障的动画参数由调用者提供。三目标均保持原始图像编码；HDRP 也不自动增加曝光或色调映射。静态设备分类与性能档位不包含历史帧捕获、相机集成和实机成本。

三管线版本的光照模型有明确差异：例如 HDRP Hair/Fabric/SSS 依赖其专用模板和管线设置，Built-in/URP 的基础系列按各自 PBR 能力实现，不声称 BSDF 等价。源项目的复杂人物图仍保留原图依赖与阻塞。

## 分类与检索

第一层是皮肤、毛发、眼球、布料、丝袜、水、金属、石头、玉石、UI、UI 动效、特效、UV 动画、顶点动画；原项目的通用图独立归类。

窗口有材质分类、管线、目标设备、复杂度四个筛选条件，并能切换按材质、复杂度或设备分组。搜索覆盖中文分类、名称、英文类别、效果说明、来源、设备别名和成本说明；空格分隔的词必须同时匹配，英文不区分大小写。例如：

- `金属 氧化 URP`
- `布料 Pad`
- `丝袜 网纹`
- `UI 擦除`
- `顶点 PC`

分类下拉的图数按所选管线统计，方案总数为全库数量；“分类收录总览”给出每类三管线图数、缺版本与模型缺口。搜索和设备筛选无匹配时，可清除限制查看该分类全部版本；管线确实未收录时明确显示缺失。

研究来源位于单独的“来源研究与待适配”页。研究记录不算作可安装材质；其设备、性能没有经过图级评估，因此该页只使用分类、管线、文本筛选。

## 性能档位的依据

这里的低、中、高表示**静态复杂度建议**。所有条目的 `deviceValidation` 均为 `NotBenchmarked`，没有手机、Pad 或 PC 实机 FPS 保证。

| 档位 | 分级条件，按高到低优先 |
| --- | --- |
| 高 | 场景颜色/深度依赖或拷贝；HDRP 人物/SSS 专用模型；超过 6 个图内采样位置；或超过 180 个原生节点 |
| 中 | 透明叠加、顶点动画、超过 2 个图内采样位置，或超过 55 个原生节点 |
| 低 | 其余图 |

采样位置从节点计划统计，不是执行时采样次数。节点数也不是 GPU 指令数；模板的灯光、阴影、隐含采样、多 Pass、变体、分辨率、网格密度及透明屏幕覆盖率会影响实际开销。完整 DeepWater 为 5 个图内纹理采样位置，另有 1 个场景颜色采样和场景深度依赖；不将重复 Pass 中的相同图计算重复计作新采样位置。

设备标签独立于性能筛选：HDRP 只标记 PC；高复杂度也先归 PC；其余超过 4 个采样位置的图归 Pad/PC；其余归 Mobile/Pad/PC。它们是选择候选图的建议，不代表已针对 Android、iOS、Metal、Vulkan 或某台 Pad 完成编译/运行测试。每项还显示生成源码中最高的 `#pragma target` 声明；例如 ASE 的 URP Lit 模板默认声明 target 4.5，不能因为标为 Mobile 就认为适用所有低端手机或 GLES 版本。Pad 和手机仍需按实际芯片、图形 API、功能级别和目标画质实测。

## 一键生成 Shader 和材质

选择分类、设备、复杂度后，点击 **一键安装筛选结果**。插件只处理当前项目实际管线的已验证条目，创建可编辑的 ASE `.shader` 和对应 `.mat`。安装包携带的是已经由 ASE 生成过的图；此入口安装图并创建材质，不是在用户项目重新运行未知源码转换。

资源路径是 `Assets/ASEShaderLibrary/<分类>/<管线>/`。完全相同的 Shader 会复用；已修改的 Shader 不覆盖，另建唯一文件名。已有匹配材质会复用并保留用户数值与贴图，其他同名资源会避让。可以停止后续生成；已生成资源保留，报告记录成功、失败和未处理数量。域重载会将当前批次记为停止，不自动重放。

每次批次的 JSON 报告位于 `Library/ASEShaderConverter/LibraryBatches/`。单个条目失败不会阻止其他条目继续处理。

原创系列新材质会配置分类配色，以及适用属性的程序遮罩、法线、流动图案、序列帧与发卡覆盖小型示例纹理。示例纹理现场生成到 `Assets/ASEShaderLibrary/Shared/OriginalExamples`，色彩图使用 sRGB，遮罩使用 Linear，法线按 NormalMap 导入；已有纹理保留。它们不是原项目纹理，也不是数百套商业贴图。贴图型效果仍可换成实际资源。新材质通过所安装管线的公开 ShaderGUI.ValidateMaterial 初始化混合、关键词与 Pass，原创发卡会启用裁剪；原图适配仍需恢复源材质参数、开关、贴图、Diffusion Profile 与宿主设置，不代表已经复刻原角色。

批量生成 DeepWater 时创建 Shader、材质、线性波纹/焦散示例纹理，并同步八组功能关键词，避免新材质 Float=1 但关键词未启用。此初始化仅用于新材质，复用时保留用户修改。URP/HDRP 的颜色/深度缓冲须按卡片配置；完整工具与预制体按钮仍仅用于 Built-in。

## 生成与验证复现

- `Tools~/Build-ExpandedLibrary.py`：创建原创效果节点计划。
- `Tests/ExpandedLibraryPlanChecks.py`：逐个验证三管线结构、实际输出变化、扩展节点可达性、属性唯一性、无环及无重复结构。
- `Tests/UnityLibraryBuild.cs`：在工作区隔离项目 probe/describe，通过真实 ASE API 建图、保存、重载与编译。
- `Tools~/Collect-ExpandedLibrary.py`：仅收集成功输出，生成分类和成本元数据、三管线覆盖清单。
- `Tests/UnityLibraryBatchSmoke.cs`：调用实际批量入口，检查材质 Pass、重复生成保留修改、停止、管线/路径/哈希保护。

原图或角色画面比较、完整变体覆盖及硬件基准是另外的验证项目，本次不将编译通过视为这些项目已完成。
