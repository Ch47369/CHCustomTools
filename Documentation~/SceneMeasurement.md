# 场景测量

CH自定义工具集 0.5.0 在 **Tools → CH自定义工具集 → 场景工具 → 距离 / 角度测量** 中提供测量功能。无需另装独立测量包，也不打开第二个功能窗口。语言使用设置页中的统一中文 / English 选项，默认跟随 Unity。

启用“在 Scene 视图中启用测量”后，左键放置顶点；右键单击或 Enter 完成直线 / 折线。放置三个或更多顶点后回到起点闭合，可测共面多边形的面积和周长。Shift 限制到世界坐标轴，Ctrl / ⌘ 吸附已有端点；可启用网格或表面吸附。Backspace 撤回草稿点，Esc 取消草稿，再按一次退出测量。

拖动已有顶点可调整形状；拖动线段可平移整条记录。面板中可修改标题、颜色、可见性，定位或删除记录。添加、编辑、拖动、删除和清空支持当前活动场景内的 Unity Undo / Redo。切换功能页、关闭工具窗口或脚本重载会停止输入捕获；记录仍可见，可单独关闭其显示。

长度按 **1 世界单位 = 1 m** 显示，不推断模型文件的真实单位。角度为相邻两边的较小夹角，范围 0–180°，包括 0° 和 180°；不是凹多边形的反角。面积是共面、无自交闭合边界的面积，支持凹多边形；非共面、自交、重合边或退化边界不提供有效面积。拖动后出现无效面积时显示“无效边界”，保留顶点供修正。

表面拾取比较 Collider 与当前编辑 Stage 内可见静态 MeshFilter / MeshRenderer 的命中距离，使用最近结果；不会给模型添加碰撞体。关闭的 Renderer、Scene 隐藏、相机图层过滤均适用于静态网格索引。不烘焙 SkinnedMeshRenderer 当前姿势；Shader 顶点位移和 GPU 形变也不包含在静态网格求交中。无法拾取时使用 y=0 参考平面；几何变化后可点击“重建”。首次为复杂模型建立 BVH 可能有可见停顿，未做大型场景性能基准。

记录位于本机 EditorPrefs，按项目路径和场景 GUID 隔离，不会写入场景文件或创建运行时物体。首次保存 / Save As 保留当前记录；未保存场景只在当前编辑器会话中有独立身份。关闭并丢弃未保存场景后不保证恢复；团队共享或 Git 同步不包含本机测量记录。移动项目目录会产生新的项目身份。切换活动场景会保存记录并结束草稿 / 拖动，当前场景的 Undo 历史随之结束。

## 从旧 WorkBuddy 工具导入

已审查用户提供的 `com.unitytoolbox.distance-measure` 1.1.0。原插件及所在项目保持原样，新代码使用 `CH.CustomTools.Measurement` 命名空间和独立 GUID，允许迁移期间共存。

1. 先关闭旧插件的场景测量开关，避免两个插件同时处理输入。
2. 打开原来的已保存场景，在新面板点击 **导入本场景旧版记录（保留旧数据）**。
3. 新工具读取同一电脑当前场景的旧 EditorPrefs 记录，复制到新的项目 / 场景存储中；保留旧偏好字节，不修改原场景或原插件。相同记录 ID 不重复导入。
4. 确认记录后可移除独立包。导入不能找回旧插件已覆盖或未保存的记录；未保存场景没有稳定旧 GUID，需先保存。

原始代码审查发现闭合周长少算末边、后方 Collider 抢先命中、未保存场景记录混用、缺少 Undo、首存迁移和场景交互状态清理等问题。本版已修复，并校验损坏存储不被新数据覆盖。实际验证和原始文件哈希见 `Evidence/Measurement050`；旧工具文件未被改写。
